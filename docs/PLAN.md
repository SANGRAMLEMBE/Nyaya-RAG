# PLAN — 8 weeks, 4 milestones

Full-time solo build. Rule: a slip degrades scope to a smaller-but-complete
milestone, never to a broken one. Tag a release at every milestone.

## Weeks 1–2 → M1 "v0.1, resume-ready"  ◄── WE ARE HERE (Day 1)
Corpus ~25 acts · era layer + IPC↔BNS mapping CSVs · hybrid retrieval
(bge-m3 + BM25 + RRF + reranker) · local generation (Qwen2.5-14B via vLLM)
· citation verifier · 150-q gold set · ablations in RESULTS.md · Streamlit UI
· paper-style README · demo video · tag v0.1.

## Week 3 → corpus scale-up
Priority-2 + ~75 more acts · SC judgments (3–5k, Indian Kanoon API vs e-SCR
decision gate — check commercial terms before paying) · judgment parser
(title/citation/bench/held) · MinHash dedup.

## Week 4 → M2 "case-law-aware"
Judgment chunks indexed · query router (rights/procedure/section/case) wired
to era filter · gold set → 300 q incl. case-law · re-run ablations · tag v0.2.

## Week 5 → synthetic data, fully local
15–25k grounded QA pairs generated by local Qwen 32B/72B from our chunks ·
citation verifier as automatic quality filter · refusal/disclaimer examples ·
contamination check vs gold set.

## Week 6 → M3 "fine-tuned beats base"
QLoRA SFT on Qwen2.5-14B (4-bit NF4, TRL) for citation discipline, grounding,
refusals — NOT legal facts · before/after eval table · tag v0.3.

## Week 7 → DPO (headline result)
Preference pairs from eval failures (hallucinated vs corrected answers) ·
DPO run · measured drop in citation hallucination · Hindi pilot if ahead.

## Week 8 → M4 "v1.0"
Expanded red-team · GGUF quantization + CPU-laptop benchmark (proves
offline-first) · final technical report · advocate spot-check of 50 answers
if obtainable · tag v1.0.

## Deferred (post-v1.0, product track)
Tauri desktop app · High Court data · Hindi full support · lawyer-reviewed
terms of use + Advocates Act compliance review (MANDATORY before any sale).
